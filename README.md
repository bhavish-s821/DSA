This repository contains simple C programs based on basic programming concepts such as arrays, loops, sorting, and structures.

## 📚 Programs Included

### 1. Student List

**File:** `students.c`

This program reads the names of `n` students and displays them.

#### Concepts Used
- Arrays
- Strings
- `for` loop
- Input and output

#### Working
1. Read the number of students.
2. Read the name of each student.
3. Store the names in an array.
4. Display the student names.

---

### 2. Bubble Sort

**File:** `bubble_sort.c`

This program reads `n` numbers and sorts them in ascending order using the Bubble Sort algorithm.

#### Concepts Used
- Arrays
- Nested `for` loops
- Conditional statements
- Swapping
- Bubble Sort

#### Working
1. Read the number of elements.
2. Read the elements into an array.
3. Compare adjacent elements.
4. Swap them if they are in the wrong order.
5. Repeat the process until the array is sorted.
6. Display the sorted array.

#### Example

Input:
text
50 20 40 10 30

Output:

10 20 30 40 50
